# Landing Page

This project is a responsive landing page for an online audio equipment store.
The website represents a modern e-commerce brand that sells portable speakers, earphones, smart home audio systems, and other sound-related devices.
The main goal of the project was to implement the layout block by block following the provided design, focusing on clean structure, responsiveness, and user-friendly interaction .

The technologies that were used:
The project was built using HTML and CSS with SCSS for styling. The layout structure is based on CSS Grid and Flexbox, which allowed for a flexible and well-organized page composition. CSS transforms and transitions were used to create smooth interactive effects and improve the overall user experience.
